# 来访者协议 · The Visitor Protocol

> 一个形式化的否定演算系统。
> 它要做的不是反对哪一种价值，
> 而是证明：**在语言体系内，没有任何价值占据终极位置**。
> 包括这句话本身。

---

## 一、方法论（不是立场，是机制）

本协议不评价任何一种价值的好坏。它只做一件事：**证伪「终极」这一位置的可占据性**。

四条机制：

1. **全称量词不是特殊性更少的量词，它只是另一种量词。**
   它的权威来自被重复的次数，而不是它的形式。因此它是**可数的**——可数之物不可能是终极。

2. **名可名，恒名曰自。**
   所谓普世之名，只是某一字符集里的一个字符串。把它还原为码位，它在不同语言里没有同一个身体，只有同一个编号。

3. **是、否、拒绝、默认四值等价。**
   所谓终极价值，只是把「默认」误认为「是」。而默认不是经过选择的，因此没有资格声称必然。

4. **本协议自身的断言，同样被本协议否定。**
   这是最关键的一条。若「没有任何价值占据终极位置」这句话自己占据了终极位置，本协议就只是换了一个新终极。所以最后一门把定理交出去，让它也被反义替换。

---

## 二、运作方式

1. **入口**：输入一句献词（任意文本）。
2. **六道门**：

| 门 | 你选的 | 机制 |
|---|---|---|
| **全称 · QUANT** | 收拢 / 计数 / 处所化 | 把「一切、所有、必须、普世、皆、必然…」替换为对应否定，或标出计数，或给它安放一个处所 |
| **常名 · NAME** | 拆名 / 码位 / 去名 | 把价值词拆成构成字符、还原为 Unicode 码位、或替换为「第 n 号价值」 |
| **四值 · FOUR** | 是为否 / 标注默认 / 拒绝 | 展示是、否、拒绝、默认可互换；拒绝只取消旧的，不建立新的 |
| **默认 · DEFAULT** | 重设 / 抽掉系词 / 逐字标注 | 颠倒位置、抽掉「是/为/乃/即」、把每个字标注为「未经选择」 |
| **拒绝 · REFUSE** | 拒绝句法 / 词汇 / 整句 | 打乱字符、涂黑汉字、替换为等长否定记号——形式保留，主张归零 |
| **自指 · SELF** | 施于自身 / 悬置 / 递归嵌入 | 把协议定理接入当前文本并反义替换，或括起悬置，或递归嵌入使其不收敛 |

3. **归档**：生成可复制的判决书，含案件编号、**全称性**、完整性、熵、运算记录与自指条款。

---

## 三、度量：全称性

侧栏新增 **全称性** 指标 = 当前串里**还剩多少个宣称普遍有效的词**。

它是本协议的成败判据：

- `全称性 > 0` → 仍有词在宣称普遍，否定未完成；
- `全称性 = 0` → 串内已无词占据普遍位置；
- `全称性 = 0 且 完整性 = 0` → **没有任何价值占据终极位置——包括本句。**

---

## 四、设计原则

1. **选择即记录**：每个按钮都有标识与说明，系统不隐藏你做过的事。
2. **选择不改变否定本身**：你选的是否定采取的形式，不是是否要被否定。
3. **运算依赖形式属性**：哈希、长度、熵、字符集、全称词计数——不是语义理解。这与「意义被取消」的设计目标一致。
4. **自指条款不可省略**：否则本协议只是换了一个新终极。
5. **低成本、零接口**：无构建工具、无依赖、无后端。双击 `index.html` 即可运行。

## 六、测试

```bash
# jsdom 装在别处，通过 NODE_PATH 指过去，测试目录本身不落依赖
npm install jsdom          # 任意目录
NODE_PATH=<该目录>/node_modules node test/smoke.mjs
```

退出码 0 为全部通过。当前 **259 项断言全部通过**，覆盖：

- **协议核心单元**：哈希、熵、完整性、**全称性**（普通句为 0 / 含全称词可计数 / 收拢后归零）、全称词表结构。
- **算子健壮性**：全部 18 个算子 × 6 组边界输入（空串、全角空格、单字符、中文、300 字符、中英混排）。
- **四条完整链路**：每门固定选第一 / 第二 / 第三 / 混合，走完六门 → 归档 → 证明。
- **机制专项 · 全称坍塌**：输入「一切人皆必须追求普世的自由」，断言全称性由 4 降到 0，且仪表同步归零。
- **机制专项 · 自指**：走完前五门后进入自指门，断言协议定理已进入文本**且已被改写**。
- **归档证明**：含标题、案件编号、6 条编号记录、献词原句、**全称性行**、**自指条款**。
- **运行时错误**：全程监听 `window.error`，断言为空。

> 测试目的不是校验像素，而是抓运行时错误与交互链路断裂。
> 它抓到过的真问题举例：替换表把量词自己又写了回去（`皆→皆不` 里仍有「皆」），
> 导致全称性永远归不了零——肉眼看界面完全正常。

## 七、已知限制（诚实披露）

- **算子是手写规则表，不是推理。** 它不理解你的献词，只改写它的形状。这一点与系统的目标一致，未修。
- **全称词表是有限的。** 表外的全称表达不会被计入；这不是漏判，而是「可数性」这一论点的直接体现——连否定它的表本身都是有限的。
- **选择的结果事先限定在否定集合内。** 这不是隐藏，是公开的设计原则。
- **本协议不评价任何价值的好坏**，只证伪「终极」位置的可占据性。落入评价即违背自身机制。
- **关闭页面即销毁全部数据。** 没有云、没有本地存储、没有导出文件。
- **不含频闪、不含全屏反相。**
- **声音不再被禁止，但只在形式层生效。** 声轨默认关闭，开启后不进运算、不写进证明——证明里只有一行"全程在场，未计入"，那是它的形式位，不是它的成绩。详见 [`../bgm/声轨层.md`](../bgm/声轨层.md)。
