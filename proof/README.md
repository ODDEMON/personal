# 是 等 于 否 · 验算器

> 这不是生成器，是一台验算机。
> 输入一个命题，它对该命题反复施加否定算子，直到命题不再变化为止。
> 那一刻即不动点，即「是等于否」的一次验算完毕。

---

## 一、它做什么

对一个输入串反复施加**署名**的否定算子，直到抵达不动点（串不再变化）或材料耗尽。
每一步都在界面上写明：**用了哪个算子、它对文本做了什么**。

随机只决定**用哪个算子**，不决定**算子做什么**。全过程可审计、可复现。

---

## 二、机制

### 算子表（11 个）

| 算子 | 作用 |
|---|---|
| 反义替换 | 按反义表替换首個可替换项（是↔否、意义↔无意义、命→钱、多→唯一的原罪…） |
| 否定封装 | 把命题包进不承认它的句式（"所谓 X，不过是一种说法"） |
| 主客倒置 | 我→你、你→他、自己→那个东西 |
| 括号化 · 内部迭代 | 随机片段被标为内部迭代 |
| 删除 | 抹去 1–2 个字符 |
| 重复 | 片段再写一遍——**重复不构成肯定** |
| 时间化 | 推入"曾经 / 将要 / 从未真正"等时态 |
| 稀释 | 按 16% 密度插入定位符 |
| 抽干虚词 | 抽走"的了是在和与及就都也很" |
| 抽空 | 30% 字符被涂黑 |
| 只剩首尾 | 保留首尾字，中间全部作废 |

### 判据

- **可读性**：可辨识字符占比
- **否定度**：`1 − 可读性`
- **不动点距离**：串相等即距离为 0

不动点判定 = **串相等**（真收敛）或 **可读性 < 12%**（材料耗尽）。
二者在画面上不作区分，但判词里写清楚——**不能把"用完了"说成"证明了"**。

### 自指条款

「◎ 自指」按钮把本机公理 **「是等于否」** 喂回本机：

- 若它**未被改变** → 本机不成立；
- 若它**已被改写** → 「是等于否」成立。

这一条不可省略。否则本机只是换了一个新终极。

## 六、已知限制（诚实披露）

- **算子是手写规则表，不是推理。** 它不理解你的句子，只改写形状。与系统的目标一致，未修。
- **中文与英文规则分表**，混排时中文优先，英文部分可能只被稀释而不被否定。
- **导出固定 1080×1440**，等于当前画面，没有"预览降质、成品全清"的分离机制。
- **超过 12 步的链路在导出单页内可能放不下**，下半部分会被裁掉。
- **不含频闪、不含全屏反相。** 仅淡入、色相漂移与单次过渡；`L` 键冷静模式可关闭模糊、错位与乱码替换。
- **声音不再被禁止，但只在形式层生效。** 声轨默认关闭，开启后不进判据：同种子 + 同输入，开声与关声得到的链路逐字相同。详[见 `../bgm/声轨层.md`](../bgm/声轨层.md)。
