# ODDEMON · 文字 → 艺术字实时生成器

### ODDEMON TYPOGRAPHY GENERATOR

> 这不是梦核，不是电波，不是任何一种可以贴在墙上的标签。
> 它是一种个人特色鲜明的**反抗精神艺术**：拒绝被给定的形式。
> 文字的本质，在这里被改写为——对「是等于否」这一等式的一次可视化验算。

一个把任意中英日俄西文本实时渲染成 ODDEMON 风格艺术字的单页 Web 应用。高饱和渐变、霓虹泛光、通道错位、液化扭曲、融化拖曳、切片撕裂、噪点做旧、漂浮乱码、神圣几何结构体——全部由 Canvas 2D 逐像素程序化计算得出，**不调用任何 AI 模型或云端推理接口**，断网可用。

**English documentation: [README_EN.md](README_EN.md)**

### 闪烁的真实来源（代码级说明）

| 效果 | 参数 | 行为 |
| --- | --- | --- |
| **全屏反相** | `故障爆发 burst` | 每帧以 `burst × 3.5%` 的概率触发一次故障窗口，窗口持续 0.06–0.22 秒；窗口内每帧有 35% 概率对**整个画面**做 RGB 反相，同时叠加 +26px 的通道错位。 |
| **扫描线滚动** | `扫描线 scan` / `扫描密度 scanFreq` | 条纹以约 0.87 Hz 的相位速度滚动；`scanFreq` 拉高后空间周期可缩到几个像素，产生摩尔纹与表观抖动。 |
| **乱码字符层** | `漂浮乱码 glyphs` | 最多 90 个粒子、每帧两轮绘制，每个粒子每帧 7% 概率更换字符，形成高频局部闪烁。 |
| **单次闪白** | — | 点击「随机扰动」「预设」「导出」时全屏叠加一次 α≤0.25 的白光（旧版为 0.5，已下调），约 5–6 帧结束。属单次事件，不构成周期频闪。 |

### ☾ 低烈度模式（本次新增）

工具条上的 **☾ 低烈度** 按钮（快捷键 `L`，或勾选「运行 → 低烈度模式」）会对一组高刺激参数施加**硬上限**，渲染时取 `min(当前值, 上限)`：

| 参数 | 上限 | 参数 | 上限 |
| --- | --- | --- | --- |
| 泛光强度 glow | 34 | 故障爆发 burst | **0（全屏反相彻底关闭）** |
| Bloom 溢光 | 0.22 | 漂浮乱码 glyphs | 0.12 |
| 通道错位 rgbShift | 5 | 回声拖影 echo | 0.18 |
| 液化扭曲 warp | 7 | 错位脉冲 chromaPulse | 0.15 |
| 切片撕裂 slice | 0.12 | 融化拖曳 melt | 0.12 |
| 扫描线 scan | 0.12 | 噪点 noise | 0.10 |

开启后同时：**禁用全屏反相**、**禁用单次闪白**、背景几何线稿透明度再降 30%、CRT 覆层维持低值。画面仍保留 ODDEMON 的结构语言（色相、几何、错位方向），只是不再朝脸上打光。

内置预设 **「低烈度·可读」** 一键到位。

### ⏸ 关于暂停（诚实披露）

**暂停只冻结时间轴 `t`，不等于画面静止。** 切片撕裂、噪点、乱码替换、故障爆发直接取 `Math.random()`，仍会逐帧变化。想要真正静止的画面，请把上表参数压到 0，或直接「导出 PNG」拿静帧。此为已知限制，本次未修。

### 安装与启动

**一键启动**（会自动建 `.venv` 并装依赖，推荐第一次用）：

```bash
# Windows：双击 start.bat
# macOS / Linux：
chmod +x start.sh && ./start.sh
```

**手动启动**：

```bash
pip install -r requirements.txt   # 等价于 pip install "gradio>=6,<7"
python app.py
```

启动后访问 <http://127.0.0.1:7860>。

```bash
# Linux / macOS
PORT=8080 python app.py
# Windows PowerShell
$env:PORT = "8080"; python app.py
```

端口被占用时程序会自动向后探测 39 个端口——**端口漂移是设计行为，不是故障**。服务绑定 `127.0.0.1`，默认不对外网暴露。`outputs/` 首次启动自动创建。

除 Gradio 外，Python 侧只用标准库。

### 神圣几何结构体（本次新增）

一层以 `lighter` 叠加的线稿，**双层描边（外圈 4.5 倍宽的低透明辉光 + 内圈细实线）**，关键顶点带径向渐变辉光节点，整体带呼吸缩放。透明度随强度参数走，低烈度模式下辉光层自动压到 35%、线稿透明度再降 30%：

- **三角星组合（默认）**——按资料库《THE SEIZED TESTAMENT》的构图复刻：**六重径向对称**，三层各 6 颗带长刺的五角星芒由外向内嵌套（相邻层反向缓转），辐条与弦把外圈星连成一个整体，其下叠三层倒三角，**正中心是一枚对比色正二十面体线框**。配色遵循原稿的双色体系：主结构线取 `主色相 + 185°`，中央多面体取 `主色相 + 65°`——把主色相放在 355° 附近就会得到原稿的「暗红底 + 青线 + 黄芯」（内置预设 **「三角星·被夺走的约书」** 一键复现）。
- **正多面体线框**——居中一枚大的正二十面体自转，外圈环绕五种柏拉图立体（正四 / 正六 / 正八 / 正十二 / 正二十面体）的小型线框。顶点与棱边在初始化时按「最小非零距离阈值」程序化求出，**不是手写硬编码的边表**。
- **梅塔特隆立方**——13 节点两两全连接（78 条线），外圈两层各 6 个圆。
- **生命之花**——六边形晶格排布的等半径圆族，外加一圈包络圆。
- **曼陀罗环**——3 到 12 边的正多边形同心嵌套，奇偶层反向缓转，外加 24 根辐条。
- **同心多边形**——7 层正多边形逐层放大、相邻层反向旋转，12 × 7 个交点上落点。

## 渲染管线

```
背景层（雾团 / 网格 / 云层 / 虹彩带 / 虚空 / 神圣几何）
  → 神圣几何结构体（lighter 细线稿，叠加于任意底色之上）
  → 漂浮乱码（远层）
  → 文字层（独立画布，自动缩放适配安全区）
  → 泛光（1/3 与 1/8 两级降采样，lighter 叠加）
  → 镜像倒影
  → 漂浮乱码（近层）
  → 切片撕裂
  → 像素级后处理 ← 单次 getImageData / putImageData
       液化位移 → 桶形畸变 → 融化拖曳 → RGB 通道错位
       → 扫描线 → 噪点 → 褪色 → 对比度 → 暗角 → 全屏反相（低烈度下禁用）
  → Bloom → HUD 时间码 → 回声拖影
```

关键取舍：

- **液化扭曲手写 `ImageData` 位移采样**，不用 `ctx.filter` + SVG `feTurbulence`——后者跨浏览器支持不完整。
- 位移场按行/列预计算成 `Float32Array`，像素内层循环只做查表与采样。
- **所有高刺激参数在渲染时统一走 `eff()` 取值**：低烈度模式下自动钳到上限，避免散落在十几处 if。
- 正多面体顶点/棱边在初始化时程序化求出（最小距离阈值法），加一种立体只需加一组顶点。
- 暗角衰减表 `vig` 在 `alloc()` 时一次性算好；噪声表 `NOISE` 为 16384 点 `Int16Array`，模块加载时生成一次。
- **看门狗**：`setInterval` 每 220ms 检查一次，rAF 超过 380ms 未回调则手动驱动一帧。
- 前端挂载采用「兄弟节点插入」策略：即便 Gradio 重渲染了 `gr.HTML` 组件，渲染根也不会被抹掉。
- **界面配色不依赖外层主题**：面板自带高对比深色底，并对 Gradio 默认的 label/button 样式做显式覆盖——这是「调节栏目看不清」的根因修复。

## 已知限制与规格偏差

以下均为**代码级核实**的结果，不是猜测：

1. **暂停不等于静止**，见开头。本次未修（按需求暂缓）。
2. **随机不可复现。** 全部随机走 `Math.random()`，未实现种子化 PRNG。参数 JSON 只能复现静态配置，无法复现切片撕裂、噪点、乱码替换等逐帧随机效果。
3. **无 DPR 处理。** 画布物理尺寸固定为 `基础尺寸 × res`，由 CSS 拉伸显示，高分屏预览偏软。
4. **没有「预览降质、成品全清」的分离机制**，导出分辨率等于当前渲染精度。
5. **URL 分享只支持预设名**，无法编码自定义参数。
6. **批量变异只出 JSON，不出图。**
7. **`window.__OD_CORPUS__` 已注入但前端未使用**，文案随机化全部走服务端。
8. **低烈度模式是上限钳制，不是后端频率钳制。** 没有 `MAX_FLASH_HZ` 这类逐帧亮度实测机制，也没有 `prefers-reduced-motion` 自动检测——是否开启由用户决定。
9. **预设名称与注解不参与翻译**（数据文案）；界面语言切换只覆盖控件标签、分组名、按钮与选项。
10. **沉浸模式会隐藏服务端控件区**，落盘需先退出沉浸模式。

## 浏览器兼容性

| 浏览器 | 预期 | 依据 |

| Chrome / Edge 90+ | ✅ 良好 | Canvas 2D / ImageData / closest() / aspect-ratio / requestFullscreen 均已普及 |
